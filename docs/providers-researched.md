# 免费渠道调研结论（含"未能核实"项）

> 调研方式：官方页面抓取 + 第三方交叉核对（2026-10-10）。**抓不到的一律写"未能核实"，未编造数字。**
> 结论会过时 —— 接入前用 `probe` 复核模型名与能力声明。

## 0. 额度按"会不会欠费"分三类（最该先看的一节）

| 类型 | 用完会怎样 | 欠费风险 | 谁属于这类 |
|---|---|---|---|
| **周期性重置** | 等下一个周期自动回满 | 低（但要防"余额扣穿"） | 火山方舟（协作奖励，每天 200 万/模型） |
| **一次性赠送** | 没了，**且可能自动转按量计费** | ⚠️ **高** | 阿里百炼、百度千帆、腾讯 TokenHub、火山「安心体验」 |
| **限流型（无总量）** | 撞 429，过一会儿自己恢复 | 无（永远不会产生账单） | 智谱 Flash、硅基流动、OpenRouter `:free`、Groq、Gemini |

**要点**：真正"一直给额度"的只有第一类（火山）；但**第三类其实更耐用** —— 它没有"用完"这个概念。
第二类才是欠费源头，而它们的共同防线是**在平台侧关掉后付费**，插件熔断只是第二道闸。

## 2. 三处明确未核实（别当结论用）

1. **火山"每天 200 万"** —— 官方文档页正文是 JS 渲染，读不到原文；"200 万/天"与"50 万/天"两个数字并存于 2026 年不同来源，未替官方下结论。
2. **百度千帆** —— 官方"新用户免费额度"页正文未读到；"每模型 100 万 / 3 个月"来自第三方汇总；"是否自动转按量"存在互相矛盾的说法。
3. **Gemini 与智谱的限流数值** —— 官方都不在公开页给确切值（分别需登录 AI Studio 限额页 / 智谱控制台），第三方数值互相冲突，**一个都不采信**。

## 3. 配置建议（额度怎么填进 limits）

| 平台 | 建议 | 理由 |
|---|---|---|
| 火山方舟 | `perModel: true, tokens: 2000000, window: "day", hardRatio: 0.95` | 每天按模型重置，留 5% 余量 |
| 阿里百炼 | `perModel: true, tokens: 1000000, window: "90d", hardRatio: 1.0` | 官方明说每模型独立 |
| 百度千帆 | **按账号级保守算**：`tokens: 1000000, window: "total", hardRatio: 0.9` | 官方说法矛盾，宁可少用不可多用出账单 |
| 腾讯 TokenHub | 先按账号级 `tokens: 1000000, window: "total"`；控制台确认后可改 `perModel` | 官方文档自相矛盾 |
| 智谱 / 硅基 / OpenRouter | **不配额度**，靠 429 自动切换 | 限流型没有"总量"，配了只会误判 |
| 火山 coding plan | 不配（订阅制，超额只报 429，不会欠费） | 已由 `manualOnly` 保护 |

**通用铁律**：第二类（一次性赠送）平台，**先去控制台关掉后付费 / 打开"用完即停"**。
百炼有明确的「免费额度用完即停」开关（开启后返回 403 `AllocationQuota.FreeTierOnly`）；腾讯默认不开后付费。
插件熔断是第二道闸，不是第一道。

## 4. 国内网络下的推荐入池顺序

1. **智谱 GLM** —— 国内直连 + 明确免费 + 有免费视觉模型，fallback 链主力
2. **阿里云百炼** —— 国内直连、模型多、每模型 100 万/90 天、OpenAI 兼容（记得开「用完即停」）
3. **本地 Ollama** —— 零注册、零成本、真正不限量，最终兜底
4. **火山方舟接入点池** —— 每天 200 万/模型，额度最耐用（但要盯住余额不为负）
5. **腾讯 TokenHub** —— 一个 key 聚合 18 款语言模型、每模型 100 万，且**免费额度用尽不会自动转按量**
6. **硅基流动** —— 国内直连且有永久免费模型，限流数值待登录核实
7. **OpenRouter 免费池** —— 唯一同时满足 vision+tools 的免费池，但需海外网络且模型长尾，放链尾
