# 群聊白名单
#
# 这个文件决定机器人会在【哪些群】里回话。
#
# 【怎么用】
#   每行填一个群号，填了之后就只在这些群里回；
#   如果这个文件是空的（只剩注释），那就所有群里被 @ 都会回。
#
# 【群号在哪看】
#   QQ 打开那个群 → 群设置 / 群资料 → 群号（一般 9~10 位数字）
#
# 【改完怎么生效】
#   重启机器人：双击「停止机器人.bat」，再双击「启动机器人(静默).vbs」
#
# 【注意】
#   群里只有 @ 机器人才会回复，这是人设里定好的行为，跟这个文件无关。
#
# 【示例】把下面两行前面的 # 去掉，换成你自己的群号：
# 123456789
# 987654321
